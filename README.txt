ПРОСТОЙ НОВОСТНОЙ САЙТ

Как открыть:
1. Откройте файл index.html двойным кликом.
2. В меню можно перейти на остальные страницы.

Что есть:
- Главная: все новости.
- Каталог: только новости об искусственном интеллекте.
- Журналист: форма создания статьи (пока без базы данных).
- Администратор: простая страница администратора.

Позже для Laravel эти HTML-файлы можно перенести в resources/views.
Общие header и footer тогда выносятся в отдельные Blade-файлы.
